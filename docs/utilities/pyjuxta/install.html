Install

You need Python 3.11 or newer. The package lives in this monorepo and is not on PyPI yet, so install it from git:

python3 -m venv .venv
source .venv/bin/activate
pip install "git+https://github.com/Neurotech-Hub/Juxta6.git#subdirectory=pyjuxta"

From a clone of the repo, the same package is installed with pip install -e pyjuxta. Notebooks and example data stay outside the package, in a folder you choose, so updating the library does not touch your logs.

In Jupyter or Google Colab, the first cell can be:

%pip install "git+https://github.com/Neurotech-Hub/Juxta6.git#subdirectory=pyjuxta"

The import name is pyjuxta. Plotting is optional: pip install "pyjuxta[plot]" adds Plotly so result.show() draws the same figures as the walkthrough.

First look

Point load_deployment at a folder of device folders or zips (the iOS app's share), name the tags, and ask a question:

import pyjuxta as jx

dep = jx.load_deployment("my_deployment/", timezone="America/Chicago")
dep.set_labels({"JX_54F7A1": "Human", "JX_5C0848": "Dog"})
dep.check()                              # data-quality findings, in plain language

res = dep.proximity("Human", "Dog")
res.summary                              # headline numbers
res.tables                               # extra tables
res.show()                               # the figure (needs the plot extra)

Every analysis returns the same kind of object: the numbers, the settings that shaped them, how much of the deployment they rest on, and the caveats that belong next to them. The walkthrough's Copy the whole walkthrough as a script button gives you the calls for your own data, with your chosen settings.
