    Walk through a deployment

    pyJuxta runs in this page. Every figure and number below is computed by the library from the data you load: nothing is precomputed or typed in. Start with the example, then drop in your own files and the same steps run on them.

    Each step asks one question, gives you the settings that change the answer, and shows the Python that produced it. Settings are choices, not facts. Move them and watch which conclusions hold.
